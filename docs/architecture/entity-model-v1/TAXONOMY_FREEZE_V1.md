# Taxonomy Freeze V1

Валидация русских display-названий по данным и подготовка к **freeze**.

**Не менялись:** SQL, миграции, production, slug, структура таксономии.

Machine final: [`taxonomy_ru_v1_final.json`](./taxonomy_ru_v1_final.json)  
База slug: [`TAXONOMY_V1.md`](./TAXONOMY_V1.md) · RU draft: [`TAXONOMY_RU_V1.md`](./TAXONOMY_RU_V1.md)

---

## Freeze policy

После утверждения этого документа:

1. Labels в `taxonomy_ru_v1_final.json` считаются **замороженными**.
2. Любое изменение названия → только через **TAXONOMY_RU_V2** (или выше).
3. Slug и дерево остаются под управлением TAXONOMY_V1; смена структуры → TAXONOMY_V2.

**Статус сейчас:** `ready_to_freeze` (ждёт явного утверждения продукта).

## Этап 3. Спорные — решения

| Тема | Рекомендация | Обоснование |
|------|--------------|-------------|
| Барахолка vs Купи-продай / Маркет / Рынок | **Купи-продай** | Барахолка отвергнута продуктом; TG = куплю/продам |
| Работа vs Вакансии | **Работа** | 1122 vs 128 |
| Праздники и площадки | **оставить** | ≠ published «Мероприятия» / Events hub |
| Туризм и визы | → **Визы и путешествия** | Визы доминируют в TG |
| Домашняя еда | **оставить** | TG + FB homemade |
| Дизайн, SMM и IT | **оставить** | Частотность совпадает с самоназванием |
| Юристы vs Адвокаты | **Юристы** | Platform; адвокат в поиске |
| Авто vs Машины (MP) | → **Машины** | машин > авто |
| Животные vs Для животных | → **Животные** (Business) | Published label |

| Остаток | Другое |
| Соединители | «и»; без «/» на home/catalog |
| Латиница | только SMM, IT |

Не смешивать: канцелярит (Общепит, Прочее), сленг хаба (Муверы как label), кальки (Травел, Маркет, Home Services).

## Оставшиеся сомнения (не блокируют freeze)

1. **Электроника** — слабый lexical hit; телефон/ноутбук уходят в synonyms.  
2. **Праздники и площадки** — длиннее идеала; оставлено против путаницы с Events.  
3. **Юристы** при доминировании «адвокат» в тексте — закрыто synonyms.  
4. **Купи-продай** vs **Маркет** / **Рынок** — выбран Купи-продай; Маркет как короткий alt для nav при необходимости.
