# Platform Taxonomy RU V1

Русские **display-названия** для таксономии V1.  
Аудитория: русскоязычные пользователи в США.

**Не менялись:** структура дерева, slug, архитектура, SQL, миграции, production.

Источник slug: [`TAXONOMY_V1.md`](./TAXONOMY_V1.md) + `taxonomy_*_v1.json`.  
Machine file: [`taxonomy_ru_v1.json`](./taxonomy_ru_v1.json).

---

## Стиль (один голос)

| Правило | Да | Нет |
|---------|----|-----|
| Короткие живые ярлыки | Услуги для дома | Домашние услуги |
| Соединитель | «и» | «/» на главной и в каталоге |
| Авто-семья по роли | Автосервис / Мастера по авто / Авто / Запчасти | смесь «Машины», «Автомобили», «Авто» без роли |
| Бакет остатка | Другое | Прочее |
| Хабы | как в IA V2 | кальки Marketplace / Jobs |

## Хабы (entity)

| slug | Рекомендуемое | Альтернативы | Почему |
|------|---------------|--------------|--------|
| business | **Бизнесы** | Компании · Каталог бизнесов | IA V2; привычнее «Компании» в каталоге |
| professional | **Специалисты** | Мастера · Частные специалисты | «Мастера» узко (не юрист/бухгалтер) |
| marketplace | **Купи-продай** | Маркет · Рынок · Купи / продай | Барахолка отвергнута; язык объявлений — куплю/продам |
| jobs | **Работа** | Вакансии · Работа и подработка | В чатах — «работа»; лента включает «ищу работу» |
| real_estate | **Недвижимость** | Жильё · Аренда и продажа | «Жильё» не покрывает commercial |

### Jobs: Работа, не Вакансии

Telegram-лента смешивает найм и «ищу работу». «Вакансии» звучит как HR-портал и хуже описывает вторую половину. Хаб = **Работа**; тип найма — фильтр (`employment_type`), не название хаба.

## 6. Что звучало плохо → замена

| Было | Плохо потому что | Стало |
|------|------------------|-------|
| Home Services → Домашние услуги | калька | Услуги для дома |
| Дом и сервисы | смесь EN | Услуги для дома |
| Общепит | канцелярит | Рестораны и кухня |
| Общая практика | калька legal | Другие юридические услуги |
| Травел / визы | «травел» + слэш | Туризм и визы |
| Площадки и ивент-бизнес | калька | Праздники и площадки |
| Красота (персонал) | служебная пометка в UI | Красота |
| Фото / видео (смена) | служебная пометка | Фото и видео |
| Коммерция | звучит как торговля | Коммерческая |
| Прочее | канцелярия | Другое |
| Автомобили + Автосервис + Автомастера | разный словарь | Авто / Автосервис / Мастера по авто |
| Дети (MP) | неоднозначно | Детские вещи |
| Еда и рестораны | «еда» слишком широко | Рестораны и кафе |
| STEM в ярлыке | латиница в UI | Школа и музыка |

## 7. Поверхности (display без смены slug)

| Поверхность | Политика |
|-------------|----------|
| **Главная** | Хабы: Бизнесы · Специалисты · Купи-продай · Работа · Недвижимость. Короткие ярлыки категорий; `other` скрыт |
| **Каталог** | `recommended` |
| **Поиск** | `recommended` + синонимы из `alternatives` |
| **Хлебные крошки** | Полная цепочка; допускается длиннее (`Запчасти для авто`, `Коммерческая недвижимость`) |

Примеры разного `display_name` при одном slug:

| slug | home | catalog | breadcrumb |
|------|------|---------|------------|
| food (biz) | Рестораны | Рестораны и кафе | Рестораны и кафе |
| home_services (biz) | Для дома | Услуги для дома | Услуги для дома |
| real_estate_agencies | Агентства | Агентства недвижимости | Агентства недвижимости |
| auto_parts | Запчасти | Запчасти | Запчасти для авто |
| commercial | Коммерческая | Коммерческая | Коммерческая недвижимость |

## 8. Сомнения (оставить на продукт-ревью)
