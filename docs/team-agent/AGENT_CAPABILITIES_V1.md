# Что умеет Team Agent

Это внутренний помощник трёх партнёров Kroogy в Telegram. Он не заменяет GitHub и не публикует сайт сам.

## Что уже работает

- Принимает сообщения группы и сохраняет их.
- Молчит на обычную переписку. Отвечает, когда его позвали: `@kroogy_bot`, `/agent` или ответ на его сообщение.
- Помнит темы, краткие итоги, подтверждённые решения и задачи.
- Находит недавние сообщения по словам, даже если тема ещё не проставлена.
- Предлагает задачи и распределение. Запись остаётся предложением, пока человек не подтвердит.
- Предлагает имя ветки текстом. Ветку сам не создаёт.
- Проверяет пересечение путей файлов, если пути уже известны.
- Показывает свой статус без вызова модели: `/agent status`.
- Считает токены OpenRouter на каждом ответе модели.

## Что зависит от настройки

- GitHub только на чтение: нужен `GITHUB_TEAM_AGENT_TOKEN` и `GITHUB_TEAM_AGENT_REPO`. Пока их нет, бот говорит «GitHub не подключён» и не выдумывает ветки и PR.
- AI: нужен `OPENROUTER_API_KEY` и провайдер `openrouter`.

## Что бот не делает

Merge, deploy, правки production, миграции базы и любые команды shell. Эти действия запрещены, а не «пока не настроены».

## Как писать

- `@kroogy_bot что ты умеешь?`
- `/agent help`
- `/agent status`
- `@kroogy_bot что мы обсуждали по личному кабинету?`
- `@kroogy_bot распредели работу`
- `/agent approve <id предложения>`

Id предлагает сам бот, когда назначение нужно подтвердить. Подтвердить может только человек из списка участников.
